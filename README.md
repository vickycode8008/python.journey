# 🐍 Python Learning Plan — Abdulbari's Udemy Course

A structured, 11-week self-study plan for complete beginners learning Python through **[Abdulbari's Python course on Udemy](https://www.udemy.com/course/python-tutorial-for-beginners/)**, studying part-time (~1–1.5 hours/day).

---

## 📌 About This Plan

This repository contains one Markdown file per week, each providing:

- 📅 **Day-by-day breakdown** (Day 1–7) with study topics and hands-on mini-tasks
- ✅ **Checkbox-style task lists** to track daily progress
- 💻 **Runnable code snippets** for every exercise
- 🎯 **Weekly Goal** — one clear, measurable outcome
- 🛠️ **Mini Project / Practice Challenge** at the end of each week
- 📢 **LinkedIn Post Draft** — ready to post (100–150 words + hashtags)
- 📝 **Notes & Questions to Revisit** — blank sections to fill in as you go

## 🚀 How to Use This Plan

1. **Open the week's file** at the start of each week (e.g., `week-01.md`)
2. **Follow the daily plan** — watch the listed sections, then do the mini-task
3. **Check off tasks** as you complete them using the `- [ ]` checkboxes
4. **Fill in your notes** in the "My Notes" section at the bottom of each file
5. **Log questions** in "Questions to Revisit" and come back to them on Day 6–7
6. **Post on LinkedIn** at the end of each week using the ready-made draft

## 🛠️ Prerequisites

- Python 3.10+ installed → [python.org/downloads](https://www.python.org/downloads/)
- A code editor: [VS Code](https://code.visualstudio.com/) (recommended) or PyCharm
- Udemy access to [Abdulbari's Python course](https://www.udemy.com/course/python-tutorial-for-beginners/)

For Week 10 (SQLAlchemy) and Week 11 (NumPy), install extra packages:

```bash
pip install sqlalchemy numpy
```

## 🎯 End Goal

By the end of Week 11, you will be able to:

- ✅ Write clean, well-structured Python programs using OOP
- ✅ Work with files, databases (SQLite + SQLAlchemy), and external data (CSV, NumPy)
- ✅ Build desktop GUI applications with Tkinter
- ✅ Handle errors gracefully and write reusable, decorated functions
- ✅ Understand concurrency basics with multithreading
